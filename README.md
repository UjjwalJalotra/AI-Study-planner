# AI-Study-planner
AI Study Planner – VidyaPath

Project Overview

AI Study Planner – VidyaPath is a simple and smart tool designed to help students plan their studies effectively. It uses basic logic to organize subjects, manage time, and improve productivity. The goal of this project is to make studying more structured and less stressful for students.

---

Features

- Create a daily or weekly study plan
- Organize subjects and topics
- Simple and user-friendly interface
- Helps improve time management
- Beginner-friendly project

---

Technologies Used

- Python (basic logic and structure)
- File handling (for saving plans)
- Simple CLI (Command Line Interface)

---

How It Works

The user enters subjects, available study time, and priorities. Based on the input, the system generates a basic study schedule. It helps students divide their time efficiently and focus on important topics.

Usage

1. Run the main Python file
2. Enter your subjects and available time
3. Get a generated study plan
4. Save and follow your schedule
